# Trabajo Práctico: DOM y BOM

Este proyecto corresponde al **Trabajo Práctico Nº5**  
El objetivo es aplicar conceptos de **DOM (Document Object Model)** y **BOM (Browser Object Model)** en distintos ejercicios prácticos.
---

## Ejercicios incluidos

### 01 - Números Mágicos
- Generación de números aleatorios.
- Manipulación del DOM para mostrar resultados dinámicos.

### 02 - Generaciones
- Clasificación de generaciones según año de nacimiento.
- Uso de DOM para inputs y resultados.

### 03 - Lista de Tareas
- agregar, eliminar.
- DOM para renderizar listas dinámicas.

### 04 - Reloj
- Reloj digital en tiempo real.
- BOM: uso de `setInterval()` para actualizar cada segundo.

### 05 - Cronómetro
- Cronómetro con botones de iniciar, pausar y reset.
- DOM para mostrar el tiempo y BOM para controlar intervalos.

### 06 - Temporizador
- Temporizador híbrido con:
  - Presets acumulativos (+1 min, +10 min, +30 min, +1 hora).
  - Botones de control (play, pause, reset).
  - Alertas al finalizar (`alert()`).

---

## 🛠️ Tecnologías utilizadas
- **HTML5**  
- **CSS / Bootstrap**  
- **JavaScript**  
- **Bootstrap Icons**
---

## 📖 Conceptos aplicados

- **DOM**  
  - `getElementById`, `querySelectorAll`, `textContent`, `classList.add/remove`.  
  - Manipulación de elementos HTML.

- **BOM**  
  - `setInterval`, `clearInterval`.  
  - `alert()` para notificaciones.  
  - Control de temporizadores y cronómetros.
